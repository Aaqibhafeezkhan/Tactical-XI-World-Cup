# Tactical XI — FIFA World Cup 2026

**Build the XI. Change the tactics. Rewrite the match.**

Tactical XI is a focused tactical sandbox for the FIFA World Cup 2026. Pick a national team, choose an opponent, build an XI on a football pitch, tune the tactical controls and simulate a hypothetical match.

## Features

- 48 World Cup 2026 teams
- 1,248-player final-squad registry snapshot
- Eight focused formations
- Drag-and-drop lineup positioning
- Player roles and squad replacement
- Possession, pressing, defensive line, width, tempo and attacking-risk controls
- Simplified opponent tactical presets
- Transparent rules-based simulation engine
- Score, possession, shots, xG, turnovers, corners and big chances
- Hypothetical event timeline
- Tactical verdict generated from the actual tactics and result
- App-generated Tactical Ratings (not official FIFA ratings)
- Reset XI, Random XI and Auto Arrange
- Responsive dark stadium-inspired UI
- Vitest unit tests for lineup and simulation logic
- GitHub Pages deployment via GitHub Actions

## Run locally

Requirements: Node.js 20+.

```bash
npm install
npm run dev
```
Open `http://localhost:5173`.

### Data preparation

The first `npm run dev` / `npm run build` materializes the tournament team/player registry to `public/data/worldCup2026.json`. After that, the app reads the local static snapshot and does not call an external football API at runtime.

To refresh the snapshot:

```bash
FORCE_DATA_REFRESH=1 npm run prepare:data
```

PowerShell:

```powershell
$env:FORCE_DATA_REFRESH="1"; npm run prepare:data
```

The sync script expects exactly **48 teams and 1,248 players** and fails rather than silently generating incomplete data.

## GitHub Pages

The repository is configured to deploy automatically from `main` using GitHub Actions.

The workflow:

1. installs the Node dependencies
2. materializes the complete 48-team / 1,248-player dataset
3. commits `public/data/worldCup2026.json` back to `main` when the snapshot changes
4. runs the test suite
5. builds the Vite site with the repository Pages base path
6. uploads `dist/` as the Pages artifact
7. deploys the artifact to the `github-pages` environment

In GitHub, enable **Settings → Pages → Source → GitHub Actions** once. GitHub Pages will then publish the project at:

`https://worksOnMyBranch.github.io/Tactical-XI-World-Cup-2026/`

The Vite configuration and runtime asset handling are already set up for this project-site path.

## Architecture

```text
World Cup static data
        ↓
Tactical State (React hooks)
        ↓
Formation + positioning rules
        ↓
Simulation Engine
  ├─ possession
  ├─ chance quality
  ├─ tactical risk
  ├─ event generation
  └─ player ratings
        ↓
Match Result
        ↓
Tactical Report + Player Ratings
```

The app intentionally has **no backend, database, authentication, live match feeds, news, fantasy, betting or generic league selector**.

## Data provenance

FIFA's 2026 tournament scope is 48 nations and 1,248 final-squad players. The local snapshot script validates that exact count before writing the application dataset. The registry source used by the project identifies itself as FIFA-sourced; the app does not present its generated numbers as official FIFA ratings.

## Disclaimer

Every match in Tactical XI is a **hypothetical simulation**. Scores, xG, events and player ratings are generated by the app's transparent tactical model and are not official FIFA predictions, ratings or match records.
